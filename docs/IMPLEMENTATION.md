# 実装と検証の判断

## 引き継いだ条件

写真調、言葉の少ない少し不気味な空間。複数の資料や部屋が交差する大きな謎と、短い操作パズルを併置する。対象を見つけにくくすることで難易度を稼がない。

生成画像の文字・目盛・機構を正解の根拠にしない。正解に関わる図版は、紙の写真へ正確な SVG と操作部品を重ねて描く。素材の再生成で答えが変わらないようにする。

## 状態の契約

資料を見ることは、資料を取ることでも仕掛けを解くことでもない。解除した収納を開けてから、表示された中身を明示的に取る。所持していない道具は使えず、別室の操作は拒否する。既知の答えは資料の既読履歴なしで入力できる。

角当てと木片は支持具を取る段階で一体になり、個別の所持品から外れる。束・白紙・原型は最終作業台で再調整できる。誤った配置は戻せる。移動、リロード、保存書き出しでも途中の環・紙・束の位置を維持する。

## 検証の区別

1. エンジンテスト：到達性、衝突、保存、入手順、重複、最終鍵の一意性。
2. ブラウザ操作：描画した入力を経由した開始〜終幕、保存後の再開。
3. 目視：各拡大画面、部屋の変化、対象位置、資料の正確さ、小画面。
4. 初見プレイヤーテスト：上記とは別。AIが解を知っている検証では初見の所要時間・満足感は測れない。

調査・設計の原本と画面キャプチャは、リポジトリ外の `脱出ゲーム/4_YOTSUZURI` に保持する。

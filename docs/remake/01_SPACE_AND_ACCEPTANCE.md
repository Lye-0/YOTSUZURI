## R01の固定仕様

4m四方、高さ2.8m。中央から目高1.55mの固定カメラ。北・東・南・西を90度ずつ切り替える。漆喰の灰白壁、焦茶の木柱と腰壁、木床、低彩度の冷たい外光と小さな真鍮灯。広角の誇張を避け、同じ高さ・画角を用いる。

- 北：受渡台。左に一つの小箱（幅38cm、単一の真鍮留め金）、右に黒い本。北東寄りの扉が校正室への入口。
- 東：帳場へ続く木戸。小箱の鍵で開く導入用の通常錠。真鍮灯は北東角。
- 南：外側から鎖の掛かった格子表戸。ガラス越しに湿った路地。内側に開閉可能と誤読させるつまみを置かない。
- 西：搬出間への通路と受渡窓。窓は人が通る入口と混同しない寸法。

この導入の小箱と鍵使用は操作の確認用であり、独立した謎の問題数に加算しない。30問の成立をこの一室の操作数で代用しない。

## 画面の契約

- 写真は一つの固定比率の場面を占める。左右は写真の縦中央、接写から戻るは写真下中央。場面切替でページをスクロールさせない。
- 近づくと同じ箱・同じ机・同じ光の専用接写へ。大きな汎用dialog、共通木机、名称見出し、資料リンク一覧を通常プレイから外す。
- 物の操作領域は写真上。戸は開いたらその戸から進む。無関係な持ち物が選択されていても、箱の留め金など固有操作を妨げない。
- 持ち物は選択と観察を分離。選択した写真を使用先へ使い、設置中の物は持ち物から外れる。戻る・向きを変えると選択解除。
- 文字は任意のヒント・設定・必要な短い反応へ限定する。名前を読み上げなければ写真が理解できない状態を不合格とする。
- UIアイコンはコード図形でよい。実物の金具・道具・木枠は写真素材を使う。

## 審査する一巡

四方向を見回す → 小箱へ寄る → 留め金を上げる → 戻って全景を確認 → 再訪 → 蓋を開ける → 中身を見つける → 一部を拾う → 戻る → 残りを拾う → 鍵を選ぶ → 東の錠へ使う → 開いた戸を見る → 保存再開。

各遷移で、形、材質、周囲、カメラ位置、状態、当たり判定を照合する。PCと狭幅で実際の写真の対象へポインターを当てる。スクリーンショット枚数・DOMクリック・テスト成功だけで採用しない。

## 全編への展開条件

上の一巡を実装・目視確認した上で、ユーザーが実画面を確認できる段階を設ける。今回の依頼は直前に合意した段階制作の実行であり、最初の一室だけを全編完成と報告しない。

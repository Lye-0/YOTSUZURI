# 初見試遊を踏まえた継ぎ枠の修正

2026-09-22。42番の試遊で長短を画像から比較できず、失敗文も長さと切欠きを混同させていた。承認された5項目を実装。

新規の初期配置は四本を横向きにし、左端を同じ基準線へそろえる。表裏は従来どおり。既存セーブの操作済み方向は上書きしない。各接写は対象から同じ距離・高さ・焦点距離の斜め視点で、短い片だけを大きくする処理をしない。

失敗理由を長さ／向き／端の衝突／隙間に分ける。配置失敗時は対象の溝上で短く停止し、衝突なら片側が浮く表示にして元の位置へ戻す。失敗メッセージは画面上部へ移す。一度目のクリックは選択、選択中の木片への次のクリックは接写。ドラッグは維持し、移動した片の元位置へ枠を残さない。

0片のヒントは長さと溝の寸法から始め、配置後は隣接する端へ進む。正誤条件・解の組合せは維持し、自動回転・自動裏返しは行わない。

検証: PC1440の本番4199で長短の同倍率接写、長さ違いの拒否、衝突時の浮きと戻り、調整し直して4片配置、枠取得を実操作。1片はドラッグで配置。390×844タッチで選択と接写・奥への配置を確認し画像を目視。151テスト、型検査・本番ビルド通過。失敗理由の回帰テスト追加。新たな初見試遊は未実施。

# 型の写しを任意の補助資料にする

型の写しを使わずに進める実際の脱出条件に、進行ヒントを合わせた。

- 保護紙の取得、写しの作成、扉との照合、二つの原型との照合を全体ヒントの前提から除外。
- 原型の観察ヒントは、直接見比べる方法と任意の写しの利用を案内。
- 紙を実際に当てている間の操作案内は維持。完成した鍵がある場合は紙を回収して鍵を差す案内を優先。
- 虫眼鏡・断面模型の条件は今回の変更対象外。

検証：build 成功。関連5ファイル31テスト成功。通常アクションだけを使う全行程の状態遷移テストで、保護紙を取得せず、写しの作成・照合を省略して脱出できることを確認。これはブラウザーでの初見プレイ検証ではない。

# 支持具への自動設置と直接操作

2026-09-22。紙束を先に置くと脇に残り、回収・再設置が必要だった条件を撤去。foreedgeMountedは同じ台に紙束と支持具がそろっていることから導出する。旧セーブのmounted=falseも同じ条件で救済し、片方だけなら脇の位置を維持。並び・紙種は変更しない。

紙束の描画要素を共通化し、支持具への移動と傾斜を同一視点で連続表示。全体画面でも紙束を左右にドラッグできる。連続値は表示だけに使い、手を離した時点で既存の左・中央・右の値へ確定。支持具は台として固定し、紙の開き方を指に追従させる。上面の近くに短いドラッグ案内を表示。隅にあった三つのアイコンは撤去。

紙束の各段を操作するのは「並べ替える」状態だけ。通常の観察では束全体の左右操作だけにし、縦操作と混線させない。観察・並べ替えとも1000×800の共通フレームで束全体と支持面が収まる画角。紙束回収、支持具回収は既存の所有条件を維持。

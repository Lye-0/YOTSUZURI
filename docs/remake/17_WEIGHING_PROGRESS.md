# P19 重さが合わない本 — 制作中

西書庫の窓下に四冊の同じ見本本と、小さな棹秤を置く。P08の釣合いを発展させ、動く錘で重さを読み、真鍮金具の重さを除く。最も軽い完成品を選ぶだけでは解けない。

本体の重さは[8,8,6,8]、同じ真鍮金具は各2。初期個数[0,1,2,3]なので総重量は[8,10,10,14]。空洞の本は二番目に重い組に紛れる。全ての金具を外して比較しても、金具一つの重さを測って差し引いてもよい。

values[19]は[皿の物,錘の位置,六つの金具の所在]。皿-1=空、0〜3=本、4〜9=外した金具。金具は-1=外した状態、0〜11=book*3+slot。中央を外しても他の金具を自動で詰めない。一つの皿に別の物を置けば前の物を台へ戻す。金具を別の本へ付けても質量と画像は追従する。

錘の位置は0〜16。付属物の質量込みの現在状態で棹が傾く。本2の背だけが引き出せるが、計量済みなどの既読を条件にしない。留め金具と皿からは実際に外す必要がある。背から木片を取ると本も1軽くなる。木片を明示的に選んで戻すこともできる。

木片は13×7×3.5cmの低い斜面を持つ濃い硬木。開く背の引出しに収まる寸法とし、P21で既存の真鍮角当てと組む。同じ木片を別用途へ渡す。棹秤・本・金具・木片は写真を使い、目盛りだけ正確なネイティブ描画にする。

本編の西書庫・西向きから計量台へ入れる。台全体、棹、外した金具、各本の表紙と背は同じ写真素材・立体・配置を異なるカメラから描く。正解以外の本も同じ距離・角度で背を確認する。背→表紙→台→室内の順に戻る。

操作は投影した2D当たり判定。本を選ぶ→現物の皿へ置く、虫眼鏡で接写、現物の金具を外す。金具の選択は接写で行い、台へ戻って皿または本へ使う。錘はドラッグ、目盛りへのタップ、左右一目盛りずつの代替操作がある。ドラッグ開始時の投影軸を保持し、棹の傾きの変化で入力が振動しない。

検証: 1440×1000のマウス、390×844のタッチで各28操作（本の計量10→戻す→片方ずつ外す→背を開く→木片取得→再読込み→空の背→金具単体2）を実施。中心座標のelementFromPointを確認してから実際に操作した。タッチドラッグ0→10、木片の明示的な返却・再取得、別の本への金具の付け替えと再読込みも確認。四冊の背と室内全景を目視した。これらは作者による部分検証であり、初見テストや全編通しプレイではない。

修正した欠陥: 台全体で皿が左に切れるカメラ、四冊のうち三冊だけ過大な背の接写、平坦すぎた真鍮面、タッチで外した金具を選び分けにくい配置。途中、開発サーバーが旧campaignモジュールを保持し新操作が無反応だったため再起動し、実際に保存状態が変化することを確認した。

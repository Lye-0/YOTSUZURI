# P21 角当てと斜面 — 幾何の契約（制作中）

既に使った平らな真鍮L角当てと、背から取り出した13×7×3.5cmの木片を、現場の二枚板の支持具へ転用する。旧試作の大きな鉄製背板へ化けさせない。基台そのものは最初から東の机に一つあり、持ち出すと机から消え、P22へ置くと同じ二枚板・同じ角当て・同じ木片が見える。

下板32×28cm、厚み約1.2cm。上板は奥辺を軸に起こせる。持上げ時70度、下ろした時は挟んだ実物の高さから接触角を計算する。木片は上板の下に入れる。木片の薄い端が奥の軸に、厚い端が手前に来ると斜面全体で支える。逆向きなら軸に干渉し、横向きなら一部だけに当たって板が大きく開いたままになる。

基台ローカル: 奥の軸v=0、下板面z=0。木片の平面寸法.07×.13、中心v=.065。横位置は左端u=.115/.125/.135の三箇所。木片の四頂点の高さと軸からの距離から必要角を求める。原画の木片はローカルy=0が厚い端。回転2で厚い端v=.13、高さ.035となり、角度atan(.035/.13)に一致する。

角当ては基台u=.09〜.23,v=.015〜.155の14cm角。通常向きでは左と手前の二辺を塞ぐ。内側直角は(u=.115,v=.13)。二つの位置決めピンは角当て両端の穴に対応し、0/180度では通るが90/270度では通らない。穴の裏表や模様の違いを新たな暗号にはしない。

完成の根拠は、(1)二穴がピンへ座る、(2)斜面と上板が合う、(3)木片が真鍮の内側直角へ入り、前方と横方向にずれない。真鍮と木片の平面接触も幾何から判定する。金具の数値と木片の数値を正解定数へ合わせただけにしない。ずれた木片、穴が乗ったままの角当て、上板と斜面の隙間を写真の立体で観察できる必要がある。

板を起こす→材料を置く→材料を回す/横位置を合わせる→板を下ろす→現物を持ち上げる。持ち上げる際に支えが外れる組み方なら持ち出せないが、物は壊れず、姿勢は編集できる。常設の「合成」「正解確認」ボタンは置かない。完成後も元の台へ返して分解できるようにする。P22から取った支持具を別物へ置換しない。

開発用lab=repair&view=cradleにモデル・写真立体・操作を実装。本編へはまだ未接続。組立が単に道具二個を置く動作へ縮んだ場合は中問として合格にしない。

values21=[上板を起こす,角当て回転,木片回転,木片横位置]。初期[1,1,0,1]。板の接触角は両部品の頂点から求め、完成条件は穴の一致・斜面の全接触・前/横の制動。48候補のうち[0,0,2,0]が揃うが、候補数自体を難易度の根拠としない。cradleアイテムに同じ姿勢を保存し、手元での観察もCradleBodyを使う。元へ返して板を起こせば、角当て・木片へ分解できる。

PC1440×1000とタッチ390×844で各21座標操作。部品を置く・角当てを回す・木片を回す/横へ寄せる・板を下ろす・横から見る・持出す・同じ台へ返す・木片を外すまで通過。L形は空白の中央ではなく写真の金属面を投影した点で操作した。別の持ち物を選んだ時、前の部品の回転ボタンが配置先を塞いでいたため、材料使用中はその操作を隠すよう修正。

原画の下板初稿に実アルファがなく、インポートで拒否。画像生成による透過修正版だけを採用。木板側面の角を短くするだけでは隙間から壁が見えたため、PhotoCuboidの任意面取り面を追加した。初回の横接写/手元の画像は採否の最終根拠に使わない。手元では上面と横からを切り替えられる。

残る検証: 本編の保存・再訪・P22への設置、修復室の灯具と全景、誤った途中姿勢の画面上の応答、ヒント。作者の部分操作を初見プレイと呼ばない。

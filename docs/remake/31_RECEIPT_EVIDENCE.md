# 控えと校正箱の対応根拠

2026-09-22。三枚の複写控えをそろえると三欄ともつながるのに、返却欄だけを読む根拠が箱になかった。太い罫線やヒント文だけでは対応を一意に決められない。

受付・作業・返却にそれぞれ異なる割印を印刷し、紙を正しくずらすと二つの境目で同じ印が完成する。校正箱の錠の上には返却欄と同じ右上が欠けた格子印を刻む。紙と錠は同じReceiptSealの形状定義を使う。紙の透明余白12単位を考慮して印を分割し、接合部が紙の縁に乗るようにした。欄の罫線は同じ太さとし、終端の矢印で読む方向を示す。箱の全景・閉状態・開状態で刻印を表示する。

ヒントは、未整列なら罫線と割印をつなぐ段階、整列後は錠との照合、最後に答えという順。自動整列、正しい欄の発光、常時の答え表示、ヒント閲覧を解錠条件にする処理は追加しない。解錠数字・セーブ形式・既存の紙の操作は維持。

## 今後の修正方針

ユーザーは修正による過度な易化を望んでいない。根拠の不足と意図した難しさを区別する。修正ではゲーム内で観察可能な根拠を補い、比較・組み合わせ・解釈の手順を維持する。難易度維持のために曖昧さや不十分な手掛かりを残すこともしない。

# 折った紙の表裏の修正

2026-09-23

折った状態の裏返しが、開いた紙の面フラグを変更していたため、外側の反対面ではなく内側の頁に変わっていた。山折りでは見えている右半分が表、同じ面の左半分が裏になる。例: 二枚目の [4,5] 面（菱形・月）は、折ると5（月）、裏返すと4（菱形）。

folioFaces と foldedPages を紙面の共通モデルとし、折った姿勢を itemValues.folios[8,9] に分離。旧8要素の保存では0として扱う。開いた紙の面は変更せず、折り目の左右だけを反転。開くと元の面の組合せへ戻る。冊子の頁順、左右綴じと頁送りも同じモデルで導く。両方の折り目の側が合う場合に重ねられ、違う場合は案内を出す。ボタンは「開く」「裏返す」と明記。

検証: 実画面で開いた菱形・月→折った月→裏返した菱形→開いた菱形・月を確認。folio-correct-back.png。全16通りの同じ綴じ側の組合せで8頁が重複・消失せず、正しい読み2031は一つ。ビルド・38ファイル168テスト通過。

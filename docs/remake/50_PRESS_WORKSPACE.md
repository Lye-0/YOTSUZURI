# 刷り機の作業画面統合と表裏判定

2026-09-22

## 操作・配置

版台と紙棚を一つの作業画面へ統合。旧bed/paper視点の保存記録も統合画面で扱う。紙を置く際の全景への自動復帰を撤去し、紙の設置・持ち上げ・版交換・印刷・取得を同じ画面で実行する。完成見本だけ独立拡大し、戻ると作業へ復帰。

作業紙、予備の版、新しい紙、見本を台の内側に再配置。台上の原版と紙は余白を確保し、位置を左右へずらしても台からはみ出さないよう縮小。紙の移動と二枚の版の交換を投影変換の遷移で表示。操作枠は各物に合わせる。回転・紙の裏返し・位置調整・印刷は画面下に名称付きで表示。刷り上がった紙の取得は刷った後に表示。

狭い画面では作業面を横スクロールで扱い、下の操作部は固定。PCでは全体を同時に表示する。

## 完成判定

従来は全レイヤーのface=0を要求し、裏面に二枚刷って同じ図柄を作ってもヒントがやり直しを指示していた。sameImpression は同じ印刷面から見た図柄で比較する。両面に分かれた印刷、異なる版・回転・位置の不一致は引き続き不成立。

既存保存の完成した裏面刷りは取り出す際も完成状態にできる。取得した紙の観察面は実際に刷った面に合わせる。ヒントも同じ判定を使用する。以前の「表のみ唯一」というテストは、表または裏の同一面という二通りへ更新。

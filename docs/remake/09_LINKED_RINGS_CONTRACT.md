# P11 三環の検討

2026-09-21。未実装の見た目を完成済みと扱わない。

参考：[ChinesePuzzles.org — Chinese Nine Linked Rings Puzzle](https://chinesepuzzles.org/nine-linked-rings-puzzle/)。同サイトの三環の説明では、先端の輪は常に動かせ、それ以外は先頭に残っている輪の次だけ動かせる。三環なら、一番・三番を外し、一番を戻し、二番・一番を外す五手で解ける。

この構造を短問へ使う候補。P01の「塞いでいる順に全て取る」と違い、一度戻す判断が生じる。多数の輪にして手数だけ増やさない。

内部では輪が掛かっている状態を3bitで持つ。初期7から6→2→3→1→0が最短。輪0は常に操作可能、輪1は輪0が掛かっている時、輪2は輪1が掛かり輪0が外れている時。既読フラグを条件に加えない。

写真はこの拘束を説明できる実物の構造を必要とする。三つの飾り輪にルールだけ付けた画面は不合格。連結・支持棒・長い輪の通り道を目視で追えない場合は採用せず、別の実物機構へ変更する。

解除後の長い輪で小箱の留めを外し、中の紙止めピンを取る構成を検討する。長い輪そのものが、別形状のU字ピンへ変わる表現にはしない。

最初の生成候補`exec-ad801957-ebde-4ce3-b3de-81c08700149b.png`は不採用。輪が三つあるだけで、隣の輪を通る支持棒が描けておらず、実際の拘束を説明できない。`public`へ取り込んでいない。論理モデルのテストは写真の機構の合格を意味しない。画像の量産へ進まず、構造の検討を続ける。

補助資料：[Cleve Moler — Patience Chinese Rings Puzzle](https://blogs.mathworks.com/cleve/2017/02/06/patience-chinese-rings-puzzle/)。こちらの公開シミュレータの説明でも、先頭・その次・先頭以前の輪の状態が操作可否を決める。本文を確認したが、参照図のブラウザ取得は失敗しており、図を確認したとは扱わない。

# 透かし台の操作修正

2026-09-22。候補選択と拡大が同時発動して毎回同じ原紙側を中心に映すこと、選んだ候補が元の場所にも残ること、何も比較していない状態でも空の布が押せることが操作結果の混乱を招いていた。

候補クリックは右の比較台への移動だけに変更。比較中の組を表示し、裏返す・上下を反転・比較を拡大・布へ置くをラベル付きで分離した。比較中の紙は元の位置へ重複描画しない。拡大から布へ置くと全体へ戻る。布の直接クリックも維持し、比較中の紙がない空スロットは操作対象から除外する。

候補と布上の紙の当たり判定は、紙束の実際の厚みを含む高さから投影した四角形へ合わせた。44pxへ一律に広げる処理をやめ、斜めの余白もクリック対象から除く。ON時の枠はその投影形状を描く。

本番4199・PC1440で5候補すべての選択先、明示拡大、上下反転、布への移動を確認。390×844タッチで候補選択、比較拡大、裏返し、3組の配置、六折の取得まで確認。取得値は[2,3,0,1,4,5]。画像watermark-table/detail/mobile-fixedを目視。149テスト、型検査・ビルド通過。原紙との比較条件や正誤判定は変えていない。UI Evolveの操作関係・状態表現基準を適用し、既存知見で説明できるためグローバルスキルの重複更新は不要。

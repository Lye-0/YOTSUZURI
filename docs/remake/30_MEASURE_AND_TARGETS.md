# 切断位置と操作枠

2026-09-22。P05の見本は左17%、切断用の消去領域は左13.7%、クリック領域は左14.5%と異なっていた。そのため切り取る量と見本の右端が視覚的に一致しなかった。

紙のない既存写真を背景にし、既存写真内の紙の質感を切り出して紙面として配置する。見本、紙、切断領域を左17%・単位2.8%で統一。残った紙は元の質感の対応部分を表示し、縮めない。全景も左39.8%・単位1.05%で統一。切った見本は回収した長さを表示し、戻すまでは交換できない。既存セーブと切断の成立条件は維持する。

操作枠は個々のボタンにmarkedを付ける方式をやめ、outlines設定から共通の写真内ヒット領域へ適用する。HTMLボタン、SVG領域、数字つまみ、封筒のドラッグ範囲、控え用紙を含む。無効な操作は表示しない。既に枠のあるナビゲーション・アイコンボタンは既存表示を使い、拡大鏡の移動面全体は本を覆わないため囲まない。書架は見える取っ手の枠を使う。

## 検証

本番4199で5種類の見本を実クリックして選択・切断・返却。見本右端と残った紙左端の差は表示丸めを含め0.01px未満。切断領域はONで黄色枠、OFFで枠なし。再読み込みと全景再訪も確認。390×844のタッチで6の紙片を選び、ナイフで切断し実保存値6を確認。隣り合う見本のタッチ領域が最小高さによって重ならないよう、この領域だけ写真の寸法を優先した。

札入れSVG、数字つまみ、封筒の投影ボタンの枠色も確認。measure-before/after/wide/mobile.pngを目視。PC実操作中の実行時例外なし。148テスト、型検査・ビルド、素材検査を実行。

UI Evolveの操作関係・代表状態確認を適用。写真上の操作と実際の対象座標を合わせる既存知見の具体的適用であり、グローバルスキルへの重複追記は不要。複数TSXの変更はReact Best Practicesも参照し、状態複製や追加effectを導入せず既存Worldから描画する。

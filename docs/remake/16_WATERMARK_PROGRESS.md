# P17 透かしの束

西書庫北東の作業台へ本編接続。左の原紙見本と、候補二折の外紙を右の透過光で比べる。型の形だけでなく、折り目の側、欠けた角、透かしの位置を照合する。P06で見た裏写りの考え方を使えるが、既読を条件にしない。

## 原紙と状態

五組の候補は各二折。0・2・4が原本の紙。1は同じ印でも折りに対する位置が異なり、3は同じ位置でも印の向きが異なる。2は初期に裏向き、4は上下逆。写真自体の折り目と欠けも一緒に動く。全ての表裏・上下の組合せを調べ、印だけなら誤紙も合うが、折り・角・位置を含めると三組だけが残ることを検査した。

values[17]は[光台で見ている候補,整理布0,整理布1,整理布2]。-1は空。光台には各折から取り出した外紙を載せ、残りの束は元の位置に残る。布へ置くと外紙を戻して二折をまとめ、折りの向きを布へ合わせる。別の束がある場所との交換でも片方が消えない。向きはgathering:flip/rotateの個別フラグで保存する。

整理布には三組を置く。短い現物の表示「六折」で必要量を示す。誤った三組も持ち出せる。手元の「紙の束」を明示的に選び、整理布へ戻して交換できる。正しい紙を揃えたかという記録は残すが、取得は正誤で止めない。

## 六折の同一性

候補と実物の対応は[[0,1],[6,7],[2,3],[8,9],[4,5]]。0〜5が原本、6〜9は別の紙。itemValues.gatheringsは持ち出した順の実物識別、book.orderはその六つのスロットの並び順。違う整理順で持ち出した正しい紙も、同じ原本へ並べ直せる。

後半へ渡すbookHeights / bookProfile / correctBookOrder / reconstructedBookには、必ずgatheringSources(g)も渡す。引数を省略した既定値は旧保存・独立した模型用。実物識別をitem-arrangeで任意に書き換える操作は受け付けない。

ForeedgeBook / ForeedgeSceneは実物の識別で紙の厚み・写真の行・絵を選ぶ。誤紙は別の絵を持ち、正しい断片へ自動変換しない。総厚みが変わると、見本台に置いた束の高さも変える。束の上面と手元の観察も同じ折り紙写真を使う。手元表示は三面を接続した写真で、上面だけ浮く初回表示を修正した。

旧形式の取得済み原本は識別0〜5へ移行。gatherings:layoutで新保存を区別する。選び直して構成が変わった場合は本の並びを初期状態へ戻す。同じ構成を返却して取り直すだけなら既存の並びを保持する。

## 写真空間と操作

原紙・光台・整理布はparts/watermark、作業台はparts/archive/bench-*。仕様はprompts-watermark.json。原紙の印は紙面の模様なので正確なネイティブ描画。物理的な紙・木・布・折り・欠けは生成写真。

作業台の初回は側面写真に写った脚が板状に見えたため、同じ写真を天板・幕板・四本の脚の各面へ割り当て直した。東西書庫の同じ実寸空間に置き、全景・接写・隣室から同じ物を見る。回転・裏返し・持ち出しは常設の文字列ボタンを並べず、写真と小さな操作アイコンで行う。

## 検証と残作業

PC1440とタッチ390で、原紙照合、裏返しても一致しない候補、誤紙の持ち出し、手元の観察、返却、候補交換、正しい三組の取得、保存復帰を実座標で操作。source=[0,1,6,7,2,3]が勝手に修正されないことを確認し、交換後は[0,1,4,5,2,3]として保存した。各操作位置で狙ったボタンが最前面にあることも検査。

DEV lab=foreedge&stock=reorderedでは上の異なる取得順からマウスで束を交換し、像の復元とP22の判定を確認。stock=mixedでは誤紙の絵と異なる厚みを確認。P22自体の本編接続、支持具の未設置・部分設置、実景の隠し戸との照合は未完了である。

研究remake/qa/pc-watermark-*、touch-watermark-*、watermark-wide-final-bench、watermark-false-handedness/false-flipped、foreedge-reordered-stock/mixed-stockが証拠。gatherings-held-volumeは手元三面表示の改訂版。旧wrong-held画像は最初の上面表示を含むので最終外観の基準にしない。初見被験者による難易度実測ではない。

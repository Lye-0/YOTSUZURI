# 断裁片の操作枠と観察操作

2026-09-22。選択解除用の背景を通常のPhotoControlで囲っていたため、机全体の大きな枠が出ていた。紙片の操作枠も上下左右へ拡張され、選択枠との二重表示になっていた。

背景はクリックによる解除を維持して枠を出さない。紙片の操作領域は140×500の紙面へ合わせ、選択は同じ領域の強調で示す。置き場所は選択時のみ、添える紙と同寸の点線と短い案内を表示する。ドラッグは従来どおり維持。

拡大画面の端に離れていた二つのアイコンを、紙の直下へまとめた。「裏返す」「上下を反転」のラベルを添え、各44px以上の高さとした。紙と操作を一つの縦配置にし、390px画面でも見切れない寸法へ調整。

本番4199・PC1440で拡大、上下反転、表裏、選択、ドラッグによる接合を確認。390×844タッチでも二操作と閉じた後の接合を確認。PC/スマートフォン画像を目視。149テストと型検査・ビルド通過。正誤条件と写真に変更なし。UI Evolveの操作関係・代表状態確認を適用し、グローバル知見の重複更新は不要。

# 刷り機に置いた原版の回収

2026-09-25。引出しから持ち出した原版二枚を刷り機に置くと、状態処理では回収できたが、画面からその操作を実行できなかった。

- 刷り機の操作列に「原版二枚を持ち帰る」を追加。紙が版に重なっている間は押せず、持ち上げると使える。
- 状態処理にも紙が重なったままの回収を拒む条件を追加。回収すると二枚を組として持ち物へ戻し、刷り跡は紙に残す。
- 間違った二枚が刷り機にある場合、ヒントで回収と引出しでの交換を案内。既に刷った紙は新しい試し紙に換えられる。
- 回収後も引出しへ一枚ずつ戻し、別の二枚を選び直せる。

検証：`plates.test.ts` で誤版の設置→一度刷る→紙を持ち上げる→二枚回収→保存再開→引出しで交換→再設置→新しい紙で完成まで。`press.test.ts` と `hints.test.ts` を含む29テスト通過。PCと390pxタッチ画面でボタンと回収後の表示を確認。スクリーンショットは研究側 `remake/qa/press-plate-retrieve-*.png`。全編の初見試遊ではない。

UI点検は `ui-evolve` の action-relationships と verification の既存知見を適用。新しい汎用規則を示す証拠ではないため、スキル本体の追記は行わない。

# 四片の継ぎ枠と返却記録

P24は36cm×30cm、幅3cm・厚さ1.8cmの四片の半欠き枠。長い二片・短い二片の長さ、向き、各端の上半分／下半分を照合する。既に置いた片と衝突する状態は置けず、外して裏返せる。特定の入力順だけを正解にせず、現在の接合形状が成立すれば枠として持ち運べる。

`FrameBody`を原型庫、持ち物、今後の製本室で共用する。取得後に別の完成画像へ置き換えない。枠の所在はinventory/placedから判定し、元の四片は残らない。部分配置・向き・裏表、取得した構成、取り戻した構成を保存する。

## 計画の具体化

返却記録は作業台上の壁に保管し、枠と別に取得する。原案の「組んだら保管箱が開く」という結び付きを、実物の構造として説得力を持たせられなかったため、木枠の組立自体を短問とした。P26の記録の読解は原型庫入室後に並行して進められる。P28とP30は組み立てた実物の枠を引き続き必要とする。

P26の記録は三つの小口図と受入／発送／返却の年を対応付ける。同じ右上割れ・二本の補修金具の一冊を選び、その返却年1927を使う。四桁の年であり、存在しない19月27日ではない。記録の細い図は携帯画面で拡大できる。同じ紙と印刷を拡大する。小口図は修復室・小口絵の`RepairPanelInk`と同じ構造を参照する。

## 確認

122テスト通過、直近本番ビルド成功。390pxタッチ・1440pxマウスで、部屋から接近、各片の接写、回転・裏返し・溝への配置、持ち上げ、持ち物の観察、再読込、台へ戻す操作を実座標で確認。返却記録の取得・全体／小口図拡大も確認。作者検証であり初見検証ではない。

生成画像の偽チェッカー背景を実アルファで検出し、imagegenで透過を修正。薄い木の輪郭の半透明画素が立体の接合部へ入るため、材質UVを不透明な内部へ6px寄せた。組み台は写真の溝・高い面・縦壁を分け、継ぎ枠が写真表面に埋まらず同じ高さで収まるようにした。

資産は組み込みimagegen。採用はpublic/remake/parts/joinery、PNG原本は調査ディレクトリremake/masters/parts/joinery。生成プロンプトはframe-prompts.json。ゲーム全体は未完成、終盤機構と通し監査が残る。

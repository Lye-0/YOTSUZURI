# 透かし台の紙を直接動かす

2026-09-22。前回の36番修正では瞬間移動と常設操作群に依存し、紙を触った結果を追えなかった。ユーザーの再指摘を受け、机上では紙の選択・移動に統一。

一度押すとその紙を選択し、空いた移動先を点線で表示。ドラッグで紙がポインタに追従し、移動先へ放すと置ける。選択後に空いた場所を押す方法でも、短い移動表示を経て同じ結果になる。比較台の紙を選んだ状態でもう一度押すと拡大。拡大時だけ表裏と上下の二操作を表示する。

常設の比較中表示・拡大ボタン・布へ置くボタンを撤去。占有場所への自動交換をやめ、布・比較台・元の位置を明示した新しい移動アクションで一組だけ動かす。向きは配置時に勝手に戻さない。正誤判定は維持。

PCで選択だけでは進行が変わらないこと、布→比較台→布のドラッグ、拡大と表裏を確認。390×844タッチで三組を選択→比較台→拡大→布へ移し、六折を取得。空いた比較台・残った候補・布の三組を画像で目視。150テスト、型検査・ビルド通過。占有先を拒否し、別の比較紙と向きを保つ回帰テストを追加。動きを抑える設定では移動を即時反映。

UI EvolveとPink Elephant Guardを参照。却下された常設操作群を完成UIに戻さず、対象物と結果が追えることを検証。既存の関係・状態基準で扱えるためグローバルスキルの重複更新は不要。

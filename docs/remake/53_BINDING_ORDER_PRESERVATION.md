# 製本で順序を解き直させない

2026-09-23

小口の絵をつないだ束の順序は従来から book.order で製本へ引き継がれていたが、常時の並べ替え案内とドラッグ操作が、同じ謎を解き直すように見せていた。

- 製本は白紙補充を基本操作とし、通常の束ドラッグでは順序を変更しない。
- 「順序を直す」を選んだときだけ移動できる。案内・ヒントも誤配置の修正として扱う。
- 小口、標本、製本の印を bundleMarks へ集約。小口にも実際の束に対応する印を表示。
- 薄い束でも印が縮小されないよう表示座標を実際の厚みに合わせ、重複した印の描画を除去。
- 作業可能な束を接写するときは「紙束を手前で整える」で枠の外へ移し、一番下も見えるようにする。載せ替えで順序・閉じた状態を変えない。

確認: PC実画面で通常ドラッグ後も [3,0,5,1,4,2] を維持。修正モードでは移動でき、戻して終了すると同じ順序を維持。小口の印と、手前の紙束全体を目視。ビルド、製本・ヒント・全編遷移の関連テスト通過。QA: book-order-preserved.png / foreedge-bundle-marks.png。

# 継ぎ枠のドラッグと受け台の接写

2026-09-22。木片中央の小さいボタンから、木片全体の投影形状をつかめる操作へ変更。ポインタ座標を台の平面へ逆投影し、木片を立体のまま持ち上げて追従させる。手を離すと近い溝へ配置を試みる。溝外への移動では組み込み済みの木片を外す。長さ・向き・切欠きの整合は既存判定を通し、誤配置を自動修正しない。短いクリックでの接写は維持。

中央の受け台に斜めからの接写を追加し、木片を置いた後も溝の側面と重なりを観察できる。台の写真面の解像度を改善。受け台自体は一周する溝で、噛み合わせる切欠きは四本の木片側にある。台へ架空の正解形状を追加しない。

PC1440の本番4199で手前溝へのドラッグ配置と接写を確認。390×844のタッチイベントで、長い木片を短い溝へ入れる操作が拒否されること、回転後に手前溝へドラッグ配置できること、接写から取り外せることを確認。空の受け台・配置後・モバイルの画像を目視。対象3テストと型検査・ビルド通過。

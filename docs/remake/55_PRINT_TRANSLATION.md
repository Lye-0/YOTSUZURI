# 同じ横ずれの二重刷りを受け入れる

2026-09-23

二枚を同じだけ横へずらして刷った紙は、白い形と六段の幅が完成形と同じでも、絶対座標で比較するため不正解だった。保守戸が読むのは白地の幅なので、二回に共通する横移動を除いて比較する。二回の相対的なずれ、異なる面への印刷、異なる輪郭は引き続き拒否する。

ヒントは手元／台上の完成判定を先に確認し、設置部品の不足や過去の別の紙と混同しない。「台上」「手元」を明記する。

検証: 左・中央・右×表・裏の同一面の6通りを受け入れ、相対ずれを拒否。ブラウザで左へ共通にずらした紙の完成表示、台上の完成ヒント、取得後の手元の完成ヒントを確認。既存紙の描画やセーブ内容は変更しない。ビルド・38ファイル169テスト通過。QA: print-offset-hint-fixed.png。

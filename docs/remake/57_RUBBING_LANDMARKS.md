# 原型の写しを面番号ではなく外形で照合する

2026-09-23

交差する補強を写した面を一律に不正解としていた条件を撤去。描画と共通の外周五頂点・二穴の中心を使い、原型の回転、原型面の左右反転、紙の裏返し、紙の回転を合成して比較する。補強線と縁の厚みは照合条件にしない。六領域を写したかどうかは維持し、未写しの縁・穴がある状態を区別する。

両面それぞれ二姿勢、合計四姿勢が同じ外形に一致する。旧保存の交差線のある写しも消したり作り直したりする必要はない。扉と原型台の判定は同じ関数を使う。ヒントから面を指定する案内を撤去し、扉に置いた時と回した時に、一致・向き違い・写し不足を表示する。

実画面で [0,0,63,0,0] の写しを扉に重ね、二回転して [0,0,63,0,2] になると交差線を残したまま照合成功することを確認。画像: rubbing-back-accepted.png。全姿勢と旧データ、原型台までの接続をテストし、ビルド・38ファイル172テスト通過。

# 白紙標本の仮置きを任意にする

2026-09-23

製本判定にはもともと標本台での配置履歴は不要だったが、nextHintGoal が solved[23] を要求し、標本のヒントも白紙を持ってくるよう案内していた。この必須経路扱いを撤去。

標本のヒントは葉の欠損の観察と、対応する印の束へ製本台で補充する案内に統一。仮置きは希望すれば引き続き比較用に行える。既に仮置きした紙の回収も維持。

検証: 製本台に白紙を置いたまま標本を見る実画面で、取り戻しの要求が出ないことを確認。全11部屋の通しテストを仮置きしない経路へ変更し、solved[23] なしで脱出まで到達。ビルドとヒント・標本・通し操作の25テスト通過。

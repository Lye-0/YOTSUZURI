# 継ぎ枠の初見エージェント試遊

2026-09-22。ユーザー指定により新規astra/medium一人へ履歴・解法・指摘内容を渡さず、ブラウザのみで試遊。約13分半で枠を取得。中断約8分半は除外。サーバー停止とエージェント中断を確認し、同じ配信版で再開した。

本人の評価:
- 約5分でヒント1、約6分で2・3、約8分で最終ヒントを使用。長い二片を上下、短い二片を左右という最終説明が決定的だった。
- 段差は拡大、とくに横向きの木片では分かる。一方、遠近・向き・個別拡大によって長短を比較できず、最初の配置の根拠を作れなかった。
- 序盤4回の失敗は十分な視覚的根拠のない試行。最終ヒント後は4本とも一度で配置。網羅的総当たりはしていない。
- 長さが違っても「切欠きが合わない」と出て、形や表裏を疑う遠回りになった。失敗メッセージも操作ボタンに重なった。
- 仕組み理解後の組合せは納得できるが、基本条件の長短が画像から伝わらず、最終ヒントまで進む必要があった。

アクセシビリティの木片番号・溝の方向などの名前が操作発見を補助。純粋に画像だけの試遊ではない。操作名から長短や正解配置は得ていない。壁の記録の文字も拡大前に取得したが、この謎には使用しなかった。

この報告を受けた継ぎ枠の追加修正は未実施。並行した保守鍵ケースの表示修正は別件である。

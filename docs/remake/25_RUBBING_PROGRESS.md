# 原型と保護紙の写し取り

原型庫北西に、二面の真鍮原型・黒鉛・練り消しを置く。工作面は連続した縁、裏面は補強のX字リブ。P18の同じ15×9.5cmの保護紙を12×8cmの原型へ当てる。紙に写るのは現在接触した面で、誤った面でも写しを作れる。

`itemValues.tissue=[接触面,原型の方向,6区画のmask,観察面,観察回転]`。紙は手元・原型上・脇の机のいずれか一箇所に存在する。途中の写しを持ち帰って戻し、続きを擦れる。異なる接触面へ重ねる前には練り消しで消す。紙を載せたまま原型は返せない。原型へ戻す時は接触面を上に置き直し、写し自体は変更しない。

六区画は内部の進捗管理で、プレイヤー画面に区画や番号を描かない。黒鉛を選び、実物の紙を指／マウスで擦る。各箇所へのタップでも行える。観察台と手元では同じ紙・同じ写しの裏返しと回転を行う。

## 検証

127テスト通過、TypeScriptと本番ビルド成功。390pxタッチ・1440pxマウスで、誤面の写し→紙を脇へ→原型を返す→消去→部分写し→持帰り→再読込→続き→裏返し/回転→手元の観察を実座標で確認、fresh errors=[]。CDPの連続touchStart/Move/Endで全区画を一筆で擦り、mask63を確認。

原型の二つの穴は採用写真のalpha0であり、茶色い塗りではない。原型の外周は6mmの厚みを持つ。黒鉛/練り消しが接写画面から切れた問題、別の場所にある紙の操作と原型を返す操作が重なる問題、縦向きの紙に操作ボタンが重なる問題を修正して再確認した。

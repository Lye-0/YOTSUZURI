# P22 同じ束・同じ支持具で小口を見る — 制作中

旧ForeedgeSceneの大きな鉄台の写真は試作。本編ではP21で組んで持ち出したCradleBodyをそのまま南の台へ置く。既存の本編はまだ修復室へ到達できず、この機構はDEV lab=repair&view=bookで制作している。

紙はP17と同じもの。P17の紙15×20cmを90度回して、小口面の幅20cm、奥行15cmに置く。厚みは同じ単位6mm、合計13単位なら78mm。sourceはgatheringSources(g)、book.orderは6スロットの並び。間違った原紙も別の絵と厚みのまま表示する。

支持具の台座は南benchlocal(u1.18,v.10,z.823)。一方、支持具なしで先に置いた紙は(u1.72,v.16,z.823)。後から支持具を置いてもその紙が勝手に移らない。foreedge:mountedは紙を置いた時に支持具があったかを記録する。片付けて置き直せば支持具へ載る。上に紙がある支持具は先に紙を持ち上げる。既存保存の両方設置済み・flag欠落は載っている状態として移行する。

カメラは全体1000×900、束の入替え用の左端600×900、絵全体1000×500を用意。どれも同じForeedgeWorldを同じ座標から見る。最初のCSS3D接写はFaceの論理面が100pxほどに焼き込まれ、斜線が点線状にぼけた。Faceに任意resolutionを追加し、実寸を変えず12倍で紙面を描いて改善した（foreedge-room-edge-dense.png）。図版は同じ写真のアルファで紙の輪郭へ制限する。

P04の拡大鏡は任意の観察道具として使う。像の既読フラグにはしない。lens-frame写真は元の真鍮枠と木柄を保ち、中央を実アルファにした。1536×1024、透明穴の連結成分bbox[86,209,587,583]、中央と外側のサンプルalpha0を確認。元のitems/lensは所持品の写真として保持。まだ機能未実装。

残る作業: 2D投影した束の入替え/タップ代替/手元へ取戻し、左/正面/右へ傾ける操作、任意の拡大鏡、同じ像の特徴を持つ北の隠し戸、照明、本編接続、誤紙と取り違えの試行、保存/再訪、PC/タッチの実操作と目視。描画だけを完成と呼ばない。

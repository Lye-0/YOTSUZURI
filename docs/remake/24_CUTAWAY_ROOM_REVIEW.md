# 断面模型の本編接続

原型庫北東の作業台へP27を配置。元の模型写真を参照して背景を除いた完全な模型を生成し、同じ写真の筐体・三つの窓・ねじ・取っ手を全景と接写に使用する。独立ラボも現在の本編表示へ更新。

金色の受け側は[2,1,4]、下側の鋼片は各四段階。三本の接点が同じ横目地に揃う[3,4,1]でのみ取っ手を引ける。画面に数字は印刷しない。引いたままねじを変更すると部品をすり抜けるため、先に取っ手を戻す。取っ手の開閉は独立した保存状態で、過去に解いたフラグから勝手に開けない。既読ゲートは設けない。

新しい写真上の校正値: 本体1435×1096、描画viewBox21,26,1470,1029。窓中心394/562/730、底605、目地400、単位41。取っ手は同じ写真から切り出し80px移動。軸は同じ鋼材写真を使用する別の立体で、取っ手が本体から離れて見えないようにする。

模型world x7.05,y-4.84,z.82,width.94m。木の背板・台座には厚みがあり、作業台に接地する。接写・四方向・隣室の戸口越しで同じ座標。描画解像度は画面上の実サイズに合わせる。

124テスト通過。PCと390pxタッチで誤試行→三本調整→引く→引出し中の変更拒否→reload→戻す→誤形へ変更→再試行→再訪を検証、fresh page errors=[]。PC・タッチの整列と引出し画像を目視。細い軸は携帯幅では背景と色が近く読みにくかったため、金属面の明るい部分を使用。診断用赤塗りはブラウザ内の一時変更のみで保存していない。

生成は組み込みimagegen。写真とプロンプトはcutaway-adopted.json/cutaway-prompts.json。採用PNGは調査remake/masters/parts/cutaway/model.png、ゲーム用はpublic/remake/parts/cutaway/model.webp。

全編完成ではない。P25、P28〜30、搬出間と終幕、地図・記録・音・全編監査・最終素材整理が残る。

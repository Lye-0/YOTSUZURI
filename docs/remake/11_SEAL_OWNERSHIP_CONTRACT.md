# P09 封印の元の持ち主

四つの小箱と、入れ違った封印の断片を調べ、元の並びを右端の保管箱の四つの印章輪へ入力する。箱の欠けと断片の裏に付いた木片、残された印の下端を組み合わせる。観察済みフラグを開錠条件にしない。

印は四種類。0=一枚葉＋V形の根、1=二枚葉＋V形の根、2=一つの丸＋横棒の根、3=二つの丸＋横棒の根。印の上部が分かる封印の表面と、元の箱側に残る下端の印を比べる。根だけでは二候補が残る。

裏の付着片は0・2が角張った欠け、1・3が丸い欠けに対応。元の箱の痕跡を左から「横棒＋角」「V＋角」「横棒＋丸」「V＋丸」とし、元の印は2・0・3・1。二つの証拠を併用して一意になる。表面の印だけ、または欠けだけでは決めない。

入力部は右端の箱に実在する四つの印章輪。入力輪は独立して回り、重複した印も受け付ける。現在置かれている断片の並び0・1・2・3を写しても開かない。正しい並びから取っ手で蓋を開き、金属角当てと糸の見本を個別に取る。

断片を観察する時は同じ断片そのものを大きく見せ、裏へ返せる。汎用の木板や解説文のパネルへ移さない。表裏の形・色・付着片と、元の箱の欠けが対応するか画像で検証する。

実装前の具体化。まだ写真やUIを合格済みと扱わない。四つの印章輪を追加するのは、封印の復元から開錠までの操作を明確にするため。金属部品としての入力と、痕跡からの推理を分ける。

# 隠し扉の入力部の接写

2026-09-23

覆いが外れた閉じた扉では六段の機構と取っ手へ自動で接写する。描画面と同じ3D位置から各段の四目盛りの操作範囲を投影し、選んだ目盛りへ直接移動する方式に変更。現在の位置を枠で表示。同じ目盛りを再度押しても次へ進まない。誤設定で取っ手を押しても接写から戻らない。通知は上部へ移し、下の目盛りを隠さない。

PCと390px幅の画面で表示を目視。III段を2へ指定し、失敗した取っ手操作後も接写と選択を維持することを確認。390pxで目盛りの操作範囲は約47×44px。ビルド、直接入力・範囲外拒否・既存進行関連テスト通過。QA: panel-input-close.png / panel-input-close-mobile.png。

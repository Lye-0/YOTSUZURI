# 搬出間と終盤の物理的な連続性

2026-09-22。全面改修の途中記録。全編完成・初見検証・実プレイ時間の測定を意味しない。

## 搬出間

受渡口の西戸を開いてから入る。窓と戸口から見える搬出間、搬出間から見える受渡口は同じ状態を描画する。閉戸時に見えない物の当たり判定を置かない。搬出口は鍵の挿入・回転・抜去・開閉・通過を別操作として保持する。誤った鍵も抜いて修正でき、模型や本を見たというフラグでは開錠を制限しない。

P25の完了を「黒鉛で全部塗った」に置かない。同じ保護紙を現扉の金具に重ね、接触面と角切り・二穴の向きを対応させる。紙は inventory / placed25 / placed29 / placed31 のいずれか一か所。31 は扉上の置き場であって第31問ではない。

P29は原型A（右下角切り・左穴・上側補修）とB（左下角切り・右穴・下側補修）。金具と写しに合うBの付属図が、本を読む面を示す。同じ紙束の上面にある角切りが図と一致する。現在の紙束の表向きが既に正しければ、わざわざ一度誤った向きに変える操作を強制しない。

開いた裏口の向こうには開いた路地を生成し、同じ写真を結末でも使う。閉じた奥の門が脱出を妨げて見えた初稿は採用しなかった。

## P28 圧締機

三つの偏心円板の実接線から押さえ板の位置・傾きを計算する。四隅が P24 の同じ綴じ枠に収まることが条件。カムの固定暗証番号照合ではないため、等価な二姿勢を受け入れる。下げた板は枠に当たれば途中で止まり、上げ直すと調整できる。

枠と締め具は別々に持ち出す。元の台・持ち物・P30 は同じ ClampBody / FrameBody を描く。既存写真に焼き付いた旧締め具は除去した背景を採用。部品の透明領域・押さえ板・ねじ受け・支柱の重なりも確認対象にした。

## P30 製本

六つの束は P17 で取得した実 source ID、順序は P22 で並べた slot ID を継承する。白紙二つは六つの束の内部へ入る。白紙を入れた束を動かせば白紙も移る。独立した七番目・八番目のパネルとして増やさない。白紙に厚さ一単位を持たせ、表面・途中の白い小口・同じ本の輪郭を描く。

紙や枠を先に置いた場合、後で締め具を置くだけでは上へ飛ばない。明示的に枠を載せ、束を載せる。作業台の脇に置いた物、圧締中の物、持ち物の所有を分ける。

閉じる → 押さえる → 針と糸で綴じる。誤った順や白紙位置でも綴じられる。綴じた本は押さえ板を上げても閉じたまま。針でほどけばやり直せる。紙を台の前へ移し、同じ小口と六枚歯を観察する。鍵の歯は個別操作し、本から自動入力しない。歯一段と本一単位はともに6mm。取得した鍵の形は、本を後で変えても変化しない。

Book.version=2。旧保存の未使用 side は現在の物体の表向きへ移行し、旧白紙位置6は5へ正規化する。圧締と縫合を別状態として保存する。

## 実施済みの限定検証

- P28: PC1440 / touch390、誤カム→枠への衝突→上げ直し→調整→圧締→保存→枠と締め具の持出し→単体観察→戻す。
- P29: touch390、誤原型→写しを返す→もう一方へ移す→照合→再読み込み→回収。
- 搬出口: touch390、誤鍵の抜去、写しの照合、正しい鍵の回転、開閉、受渡口の窓から開いた扉を再確認、退出、結末の再読み込み。
- P30: PC1440×1000 / touch390×844、実座標で三回の束交換、白紙二か所、閉じる、圧締、縫合、解放、前へ移す、六歯調整、鍵の回収、保存後の再読み込み。fresh pageerror は空。
- P30 touch: 持ち物から紙→枠→締め具の順に置く部分配置も実操作で確認。後置きでは紙と枠が脇に残り、載せ替えてから完成させた。

終盤の限定検証は材料を持った状態を作って開始している。最初から全編を解いた試験でも、初見の難易度評価でもない。ヒント改訂、地図・記録・音、全編通し、最終画像監査、未使用物整理、標準入口の置換が残る。

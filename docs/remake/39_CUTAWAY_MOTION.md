# 断面模型の動く境界

2026-09-22。取っ手だけが移動していたため、どの境目が横移動を解放するのか読み取りにくかった。既存の写真部品をSVG内で固定部と可動部へ切り分け、中央線より下の筐体、金色のピン、下側の押上棒・つまみと取っ手を一体で80単位移動させる。上側の棒は固定側に残し、下側の後ろにはガイド面が現れる。

つまみ操作は各ピンを0.28秒で昇降、正常な開閉は0.5秒で横移動。不整合の取っ手操作はわずかに引っ掛かって戻る短い動きとし、繰り返し操作でも再生。正しい境界の発光・追加ボタン・答えの目印は加えない。開いた間はつまみを無効にし、戻した後に再調整する。動きを抑える設定に対応。

PC1440の本番4199で不正位置の拒否と停止アニメーション、正しい組合せでの横移動、固定側に残る棒、開いた状態の再読み込み、取っ手を戻して再調整できることを確認。390px幅でも画像を目視。狭幅確認はマウスで行い、実タッチの追加検証ではない。対象2テストと型検査・ビルド通過。解答値・成立条件・素材ファイルは変更なし。

# 原版の観察と試し押しの根拠

2026-09-22

## 原因と変更

原版は 900×400 の図を引出しの 850×43 に圧縮しており、接写画面でも凹凸を判断できなかった。配置用の遠景とは別に、引出しを開くと既存の高解像度写真を正しい縦横比で観察できる画面へ移る。取得前にも見られ、段番号と取得後の空の状態を表示する。

同じ画面に既存の試し押し（凸・凹の三角形とそれぞれの印影）を表示。「二枚を重ね刷りし、白く残る輪郭を読む」という目的を添える。段番号による正解表示や自動選択は行わず、選択・重ね刷りの条件は維持する。

操作は「引出しを閉める」と「この原版を持ち出す／戻す」。明示的な返却では持ち物を選び直す必要をなくした。刷り機に設置された原版をこの画面から回収することはできない。

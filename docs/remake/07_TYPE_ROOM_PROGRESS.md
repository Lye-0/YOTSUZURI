# 活字室の進捗と未解決事項

## 天秤 P08

全景・接写とも同じ三個の写真部品を動かす。左右の重さから横棒の角度を求め、皿は鉛直を保つ。二・三と五を左右に分ける二通りを許容。正解履歴があっても崩せば引出しは開かない。開けた後も重りの位置は保存する。

PCでは写真座標をクリックして[1,1,2]に配置し、取っ手を引いて開閉差分と中身を目視。390×844のタッチでは[2,2,1]を作り、再読込後に開け、中身を取得。横溢れなし。全景の開状態も目視した。研究qaのbalance-initial/open/wide-open、touch-balance-openが記録。

固定した上部を保つため、再生成の全画面交換を避け、留め棒周囲と引出しの差分範囲だけ使用。全景と接写で同じ棒、皿、重りを使う。留め棒の支持・天秤との連動をより明確にする物理表現は、最終の機構レビューで再点検する。

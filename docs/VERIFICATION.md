# 改修版の確認範囲

2026-09-22、ブランチ `remake`。通常の `/` と `/remake.html` は同じ改修版を開く。

## 実施した確認

- PC 1440×1000：初期状態から11室を巡り、材料を取得して持ち運び、製本・鍵の調整・退出・結末の再読み込みまで操作。途中の進行値の書き換えなし。
- 各機構のPC／390×844タッチ操作：誤操作、取り戻し、途中の保存、取得後の空状態、別室での再使用を段階ごとに確認。
- 本番ビルド4199：390pxで全11室の四方向を巡り、撮影した画面を目視。書庫の欠けを発見した後、東西書庫・修復室・原型庫・搬出間を再確認。1440pxでも同じ区間を再訪。
- 本番ビルドのタッチ：戸の両側からの開閉、製本台、拡大鏡の実ドラッグ、鍵の挿入・回転・抜去、退出。実行時例外・画像取得失敗なし。
- 観察記録：途中状態と拡大した返却記録を保存し、本編で表示を変えた後も見返せる。メモの再読み込み、本編セーブが書き換わらないことを確認。
- `pnpm test`、`pnpm check:assets`、`pnpm build`。旧版専用テストを除き、現行149件が通過。写真の寸法・容量・透過属性を台帳と照合。

作者が解法を知って行った確認であり、初見プレイヤーによる試遊ではない。4〜6時間は設計目標で、実測時間や難易度の保証にはしない。スマートフォンの最終全室再訪は、PC通しで得た実セーブから開始している。

## 描画で直した不具合

書庫の大きな床面・壁面・レール面がカメラの後ろまでまたぐと、特定方向でChromeの3D描画が欠けていた。各較正領域を小面に分け、カメラ前方だけを描画した。床の痕跡と図面の対応座標は維持する。

遠景の写真面は実際の表示倍率に応じて描画解像度を下げる。ただし、内部が絶対座標で構成された封筒などには一律適用しない。小口などの明示的な解像度指定も維持する。面の大きさ・当たり判定・物体の寸法を変える処理ではない。

修復室から書庫越しに活字室を斜めに見ると、奥の一枚背景の範囲外が黒く見える箇所があった。活字室の左右の壁を追加し、原版引出しと天秤は同じ現在状態を参照する。

# 改修版の状態と描画

`src/remake/main.tsx` を両HTML入口で共有する。旧版の画面への分岐、制作途中の境界、開発専用の試作入口は残さない。

`campaign.ts` の `World` を保存と操作の基準とし、機構ごとの reducer が場所・方向・所有を検証する。取得品は持ち物か設置場所の一か所に存在する。`book` と `print` は作業途中も保持し、紙の実 source ID と表示順の slot ID を混同しない。既読フラグは正しい操作を拒む条件にしない。

背景・部品・道具は `sceneFiles.ts` で一組として先に読み込む。画像が揃うまで旧状態を表示し、部屋と部品が別状態で混ざらないようにする。実物を描くコンポーネントを全景・接写・所持品で共有する。UIの当たり判定は投影した実物へ合わせる。

`Face` は世界寸法をCSSへ投影し、写真面のみ `WorldCamera` の表示倍率に応じたラスタ解像度を使う。固定のCSS座標を持つ子要素は解像度自動調整の対象にしない。カメラ後方をまたぐ壁・床は `TiledSurface` で分割する。反対側の部屋や窓は、現在の物品状態を参照して描く。

`journal.ts` の記録は世界と観察視点の固定コピー。記録用の `Remake` は操作・保存・キーボード入力を無効化し、本編へ値を戻さない。最大120件を保存し、満杯時には既存の記録を自動で消さない。メモと写真状態は別々に保つ。

採用画像は `public/remake/{scenes,closeups,parts,items}`。台帳は `docs/remake/manifest.json`。`pnpm check:assets` は未登録画像、寸法・容量・透過属性の不一致を検出する。

`docs/remake/01`〜`27` は段階ごとの設計・検証記録で、当時の未実装箇所や後に退役した試作を含む。現在の検証範囲は [VERIFICATION.md](VERIFICATION.md) を参照する。
